# code-quality 规范

## 目的
定义 vamOS 项目的代码质量标准和 CI 管道要求。

## 需求
### 需求：Python 覆盖率强制执行
CI 管道应强制执行最低 Python 代码覆盖率阈值。

#### 场景：具有足够覆盖率的 PR 通过
- **给定**带有 Python 更改的 pull request
- **当**覆盖率工作流运行时
- **那么**如果行覆盖率 >= 90% 且分支覆盖率 >= 80%，PR 通过

#### 场景：具有覆盖率回归的 PR 失败
- **给定**将覆盖率降低到阈值以下的 pull request
- **当**覆盖率工作流运行时
- **那么**PR 失败，并显示清晰的消息指示覆盖率差距

### 需求：CI 中的静态分析
CI 管道应在代码上运行静态分析工具。

#### 场景：静态分析在 PR 上运行
- **给定**带有代码更改的 pull request
- **当**静态分析工作流运行时
- **那么** ruff 分析 Python 文件
- **并且** clang-tidy 分析 C/C++ 文件
- **并且**新违规在 PR 中报告

### 需求：质量仪表板
项目应提供显示覆盖率和分析趋势的质量仪表板。

#### 场景：开发者查看质量指标
- **给定**开发者想要检查质量指标
- **当**他们访问质量仪表板时
- **那么**他们看到当前覆盖率百分比
- **并且**他们看到覆盖率随时间的变化趋势

### 需求：模块级覆盖率目标
每个 Python 模块应保持与其关键性相适应的最低测试覆盖率阈值。

#### 场景：核心模块满足覆盖率阈值
- **给定**核心 Python 模块
- **当** pytest 运行覆盖率测量时
- **那么**行覆盖率 >= 90%
- **并且**分支覆盖率 >= 80%
