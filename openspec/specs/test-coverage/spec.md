# test-coverage 规范

## 目的
定义 vamOS 项目的测试覆盖率要求。

## 需求
### 需求：最低覆盖率阈值
测试套件应保持最低 90% 的代码覆盖率。

#### 场景：覆盖率满足阈值
- **给定**测试套件
- **当**测量覆盖率时
- **那么**整体覆盖率至少为 90%
- **并且**没有模块的覆盖率低于 85%

#### 场景：覆盖率失败阻止 PR
- **给定**一个修改代码的 PR
- **当**覆盖率下降到 90% 以下时
- **那么**PR 检查失败
- **并且**覆盖率报告显示未覆盖的行

### 需求：测试类别
测试套件应包括多种类型的测试。

#### 场景：单元测试存在
- **给定**测试套件
- **当**对测试进行分类时
- **那么**所有公共类都有单元测试
- **并且**所有公共函数都有单元测试

#### 场景：集成测试存在
- **给定**测试套件
- **当**对测试进行分类时
- **那么**集成测试验证端到端工作流程

#### 场景：边缘情况测试存在
- **给定**测试套件
- **当**对测试进行分类时
- **那么**边缘情况经过测试（空输入、边界）
- **并且**错误处理经过测试

### 需求：覆盖率报告
系统应生成覆盖率报告进行分析。

#### 场景：HTML 覆盖率报告
- **给定**启用覆盖率的测试运行
- **当**请求生成报告时
- **那么**生成 HTML 报告
- **并且**报告显示逐行覆盖率

#### 场景：CI 覆盖率报告
- **给定**包含代码更改的 PR
- **当**CI 运行测试时
- **那么**上传覆盖率报告
- **并且**在 PR 中显示覆盖率增量

### 需求：覆盖率配置
覆盖率配置应可维护且有文档记录。

#### 场景：排除项有文档记录
- **给定**覆盖率配置
- **当**定义排除项时
- **那么**每个排除项都有解释原因的注释
- **并且**测试文件从覆盖率中排除

#### 场景：分支覆盖率启用
- **给定**覆盖率配置
- **当**测量覆盖率时
- **那么**包括分支覆盖率
- **并且**报告行和分支
