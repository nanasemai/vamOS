# 性能优化规范

## 目的
针对 vamOS 平台上的系统运行性能进行专项分析与优化。

## 需求

### 需求：构建优化
优化构建过程以减少编译时间和资源占用。

#### 场景：启用编译优化
- **给定**构建系统
- **当**编译目标为目标设备时
- **那么**编译器标志应包含 `-O3`
- **并且**启用链接时优化 (LTO)

#### 场景：并行构建
- **给定**构建命令
- **当**执行构建时
- **那么**使用 `-j$(nproc)` 进行并行编译

### 需求：系统运行时优化
优化系统运行时性能，减少资源占用。

#### 场景：精简日志级别
- **给定**系统的日志记录配置
- **当**在发布模式下运行时
- **那么**禁用 `DEBUG` 级别的日志输出
- **并且**限制后台网络和 CPU 占用
