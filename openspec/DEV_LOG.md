## 记录规范

每次完成重要工作后，在本文件中添加记录：

**格式要求**：
```markdown
## 2026-03-12 15:30 (1773285905)

**完成**：[完成的工作]
**关键**：[关键决策]
**问题**：[遇到的问题，无则写"无"]
**下一步**：[后续计划]

---
```

**说明**：
- `2026-03-12 15:30` 为人类可读日期时间
- `(1773285905)` 为 Unix 时间戳，供 AI 排序/查找使用
- 获取时间戳：`date +%s`

---

## 快速命令

```bash
# 获取当前时间戳
date +%s

# 查看开发日志
cat openspec/DEV_LOG.md

# 添加新记录
vim openspec/DEV_LOG.md
```
