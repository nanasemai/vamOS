# OpenSpec 工作流

## 何时使用

创建变更提案 when:
- 添加新功能（如新设备支持）
- 破坏性变更（API、配置格式）
- 架构更改
- 性能优化

**跳过提案** when:
- 错误修复
- 拼写/格式修改
- 依赖更新（非破坏性）
- 配置更改

---

## 快速命令

```bash
# 创建变更（步骤）
# 1. 在 docs/ 下创建目录
# 2. 添加 proposal.md, tasks.md, design.md(可选)
# 3. 更新相关文档
```
